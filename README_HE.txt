יעל PWA – גרסת בדיקה 0.1
========================

מטרה
-----
גרסת iPhone ראשונה ללא שרת PhotoArchive וללא Apple Developer.
האפליקציה היא אתר סטטי (PWA) ופונה ישירות ל-Google Drive API.

תיקיית השיתוף כבר מקובעת בקוד:
1g-ijAmD2LeRLU6d4AIR52aZrKy0XK2Ov

מה יש בגרסה 0.1
----------------
* התחברות ל-Google.
* פתיחת תיקיית השיתוף הקבועה.
* הצגת עץ תיקיות.
* הצגת תמונות ודפדוף.
* זום וגרירת תמונה.
* אם קיימת תיקיית Back באלבום: כפתור "גב" מחפש תמונה באותו שם.
* אם קיים TXT ב-Back באותו שם בסיס: כפתור "טקסט" מציג אותו.
* שמירת האלבום והתמונה האחרונים בדפדפן של אותו מכשיר.
* התקנה למסך הבית כ-PWA.

מה עדיין לא בגרסה 0.1
----------------------
* סיבוב ושמירה.
* Crop ושמירה.
* עריכת TXT ושמירה.
* מצב אנונימי דרך קישור שיתוף בלבד.
אלו יתווספו אחרי שנאשר שהגישה והצפייה עובדות היטב באייפון.

מה חסר לפני שאפשר לבדוק באייפון
--------------------------------
צריך ליצור ב-Google Cloud פרויקט + OAuth Client ID מסוג Web application,
ולהכניס את ה-Client ID בקובץ config.js.
לא צריך Client Secret בתוך ה-PWA.

בנוסף, צריך לארח את התיקייה על HTTPS. אפשר GitHub Pages / Cloudflare Pages / Netlify.
זה אירוח של קבצי האפליקציה בלבד; התמונות אינן נשמרות בו והאפליקציה אינה תלויה בשרת PhotoArchive.

לאחר שיש URL סופי של האתר, יש להוסיף אותו ב-Google Cloud תחת Authorized JavaScript origins.
